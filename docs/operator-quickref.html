Open the gallery → adp-lab.github.io/adp-show-graphics/gallery.html
First time — Connect to Worker. Enter:
  • Worker URL: https://adp-show-graphics.mohn-edgar.workers.dev
  • API key: shared separately by André (not in this doc)
(Remembered after the first connect.) Then pick your show's Event from the dropdown (top-left) before anything else.
The one rule: loading an image into a slot is PREVIEW only. It shows in your preview slots and the Live Outputs monitors — but it's NOT on air until you press a SEND LIVE button.

Colours = state (the same everywhere)

● Green = loaded / preview (not on air) ● Red = ON AIR ● Dark = not loaded

On the image-tile slot buttons, the SEND LIVE buttons, and the Saved-Layout H / V / Both buttons.

H = landscape output, V = portrait output — separate slots, aired independently.

Put a bug / QR live (≈30 s)

  1. On the tile in the Image Library, click Bug H or Bug V → loads into the slot (●).
  2. Position / scale it in the preview if needed.
  3. Under BUG / QR LIVE, press Bug H / Bug V / Bug H+V → on air (●).
  4. Confirm in the Live Outputs monitors (right).

Put a graphic live

Same flow: click GFX H / GFX V on the tile, then press GFX H / GFX V / GFX H+V under GRAPHICS LIVE.

Take it off air / swap

  • Press the red SEND LIVE button again (toggles off), or use CLEAR to remove it.
  • To swap: load the new image into the slot (goes ●), then press its SEND LIVE.

Layouts

  • + Save Current Layout stores your whole setup.
  • In Saved Layouts, click H / V / Both to recall. Colours: ● loaded, ● on air, dark = not loaded.

If something isn't on air

  1. Is the SEND LIVE button red? If green/dark it's only preview — press it.
  2. Check the Live Outputs monitor for that slot.
  3. Right Event selected?
Saw a ⏸ Paused (idle) badge? The gallery paused its previews after ~5 min idle to save requests — your outputs are still live. Move the mouse to resume.
